\section{CoMani Benchmark}
\label{sec:benchmark}

CoMani comprises 3 suites testing modifier, action-type, and sequential composition (Fig.~\ref{fig:benchmark}; Table~\ref{tab:comani_tasks}).
We generate 50 trajectories per atomic task using MimicGen~\cite{mandlekar2023mimicgen}.
Within each suite, initial scenes are matched wherever feasible to require instruction-dependent behavior and discourage fixed vision-to-action mappings.
We report success rates by split over 30 trials per atomic task and 10 per sequence.

\textbf{CoMani-Modifier.} With pick-and-place (\emph{put}) fixed, this suite combines 3 objects, 3 targets, and 2 modifiers (\emph{on}/\emph{right of}) into 18 tasks: 12 training/in-distribution (ID) and 6 out-of-distribution (OOD).
Each OOD object--target pair appears in training with the opposite modifier, isolating generalization to unseen combinations of familiar factors.
The ID/OOD comparison therefore tests whether a policy can apply the instructed relation to a familiar object--target pair beyond its demonstrated placement.

% OOD IDs: 0,4,7,11,14,15. Held-out on: bowl/plate, cheese/stove,
% bottle/cabinet. Held-out right: bowl/stove, cheese/cabinet, bottle/plate.

\textbf{CoMani-Action.} With \emph{right} fixed, this suite varies \emph{put}, \emph{sweep}, and \emph{rotate} across 10 tasks: 7 ID and 3 OOD.
For put/sweep, each held-out object--target pair is demonstrated with the other action; for rotation, training uses the stove knob and OOD evaluation uses cream cheese.
These tests examine whether a policy can reuse an action with familiar entities in a new combination and transfer rotation across different manipulated entities.
Put/sweep pairs share initial states and final-position goals, so success measures goal attainment rather than interaction mode.

% Internal suite: 0904. Training IDs: 0,1,2,5,7,8,9. OOD IDs: 3,4,6.
% Rotation details: dataset term "right" means counterclockwise about world +Z
% viewed from above. Knob: joint position >= 0.5 rad. Cheese: reset-relative
% signed rotation >= 0.5 rad, with tilt <= 15 degrees.

\textbf{CoMani-Seq.} This suite tests whether policies learned from CoMani-Modifier atomic demonstrations can execute 3-step instructions without sequence-level demonstrations.
\emph{Seq-ID} combines 3 ID tasks; \emph{Seq-OOD} replaces the cream-cheese task with its OOD modifier variant, giving 2 ID tasks and 1 OOD task.
Each set includes all 6 orderings, yielding 12 unseen sequences.
Seq-ID tests ordered execution and subtask transitions among familiar skills; Seq-OOD adds an unseen atomic combination while preserving the objects, targets, and sequence orderings.
Comparing the 2 sets assesses how atomic compositional generalization carries over to long-horizon execution.
